A split editor shows the same document twice. Each half scrolls on its own, and what you type in one appears in the other at once. Menu commands and the status bar work on the half you clicked last; the minimap follows the first half. Drag the divider to change the sizes.

Folding hides a block and shows … in its place: { } blocks in C-like languages, Swift, JavaScript, JSON and CSS; indented blocks in Python, YAML and most other languages; sections under a heading in Markdown. A triangle next to the line number marks each block (▼ open, ▶ folded). Folding only changes the view: the text, Undo and saving are not affected. A folded block opens when you edit it or when the caret moves into it (Find, Go to Line, the function list). In a split editor, each half folds on its own.

The function list on the right shows the document’s functions and classes (headings in Markdown and LaTeX, sections in INI and TOML files, targets in Makefiles), nested as they are indented. Click a name to jump to it; type in Filter to find one by name. The function the caret is in is selected. The list follows your typing after a short pause. It recognizes definitions line by line, so a definition split over several lines may be missing; definitions inside comments and strings are skipped. Your own languages have no function list.

The minimap on the right shows the whole document in miniature, in the same colors as the text; the shaded part is what the window shows. Click in it to jump there, or drag the shaded part to scroll.

The status bar shows the caret’s line (Ln), column (Col) and position in the document (Pos), and the number of lines and characters in the document. Characters are counted as you see them: an emoji or a CRLF line break counts as one.

With several cursors, typing, Return, Tab, Delete, the arrow keys (also with Shift, Option or Command), Copy, Cut and Paste work at every cursor, and one Undo step reverts each change at all of them. Paste puts one line at each cursor when the clipboard has exactly as many lines as there are cursors. Press Esc or click in the text to go back to one cursor. A cursor added on a shorter line goes to its end; the next one goes back to the original column.

The ASCII Character Panel lists the codes 0–255 (128–255 as in Windows-1252, the common Western code page) with their hex, Unicode and HTML codes. The character goes where you would type, at every cursor. If the document’s encoding can’t store it, NotepadS offers to convert the document to UTF-8 first.

In overwrite mode (OVR in the status bar, orange caret), each character you type replaces the one after the caret. Line breaks are never overwritten: typing at the end of a line makes the line longer. Return, Tab and Paste insert as usual. Each window has its own mode; new windows start in insert mode (INS).

With Show Invisibles, spaces appear as ·, tabs as →, and line endings as ¬ (LF), ↵ (CRLF) or ← (CR).

When you press Return, the new line keeps the indentation of the line above. Whether Tab inserts a tab or spaces is set in Settings.

NotepadS never changes what you type: smart quotes, dashes, spelling correction and text completion are off.

Comparing two texts

File › Compare With compares the front document with another open document, with its Last Saved Version on disk (to see what you changed), or with any Other File…. The two texts appear side by side and scroll together; equal lines stay level, with hatched gaps opposite lines that exist on one side only.

  • Red: lines only on the left. Green: lines only on the right. Yellow: changed lines, with the changed characters marked.
  • The arrows (⌥⌘↑, ⌥⌘↓) jump to the previous and next difference.
  • Ignore whitespace and Ignore case compare more loosely. Different line endings (CRLF, LF) never count as a difference.
  • The window shows the texts as they were when you opened it; Refresh compares again after you edit.
