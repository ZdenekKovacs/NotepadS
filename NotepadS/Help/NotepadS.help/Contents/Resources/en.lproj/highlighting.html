Syntax highlighting

Colors for code and data files.

NotepadS colors the text based on the file’s language. The language is detected from the file name or extension, or from a #! line such as #!/usr/bin/env python3. The status bar shows it; click it to choose another language for this window.

Supported languages: C, C++, CSS (also SCSS and Less), Diff, Dockerfile, Go, HTML, INI, Java, JavaScript, JSON, Makefile, Markdown, PHP, Python, Ruby, Rust, Shell, SQL, Swift, TOML, TypeScript, XML and YAML.

The colors follow Light and Dark mode. For very large files (over 10 MB) or files with extremely long lines, highlighting turns off to keep editing fast; the status bar then says (highlighting off).
