NotepadS Help

Text tools

The Text menu changes the selected text, or the whole document when nothing is selected.

Every tool is one step: Edit › Undo (⌘Z) restores the text. If the text isn’t valid input (for example broken JSON), NotepadS shows where the problem is and changes nothing.

ToolWhat it does
Format JSON / Minify JSONIndents JSON or removes its whitespace. Keys stay in their order and numbers stay exactly as written.
Base64 Encode / DecodeConverts text to and from Base64 (UTF-8).
URL Encode / DecodePercent-encodes text for use in URLs, and back.
HashCopies the SHA-256, SHA-512, SHA-1 or MD5 hash of the selection or of the whole document, or replaces the selection with it. The document hash matches what shasum prints for the saved file.
UPPERCASE, lowercase, Title CaseChanges letter case.
camelCase, snake_case, kebab-caseConverts names line by line, for example HTTPServer → http_server.

Lines

Text › Lines works on whole lines: every line the selection touches, or the whole document when nothing is selected. Each line keeps its own line ending; new line breaks use the document’s style.

ToolWhat it does
Duplicate Line (⌘D)Copies the caret’s line (or the selected lines) below itself.
Delete Line (⇧⌘K)Deletes the caret’s line (or the selected lines).
Move Line Up / Down (⌥⌘↑, ⌥⌘↓)Moves the caret’s line (or the selected lines) past the line above or below.
Join Lines (⌃⌘J)Joins the selected lines into one, with one space between them and the indentation of the following lines removed. Without a selection, joins the caret’s line with the next one.
Split Lines…Splits lines longer than the number of characters you enter, at spaces. Longer words stay whole.
Sort Lines Ascending / DescendingSorts alphabetically, ignoring upper and lower case, with numbers in numeric order (file2 before file10).
Reverse Line Order, Shuffle LinesReverses the lines, or puts them in random order.
Remove Duplicate LinesKeeps only the first of equal lines anywhere in the text.
Remove Consecutive Duplicate LinesRemoves a line equal to the line right before it, like uniq.
Remove Empty LinesRemoves empty lines and lines with only spaces or tabs.

Whitespace

Text › Whitespace works on the selected lines, or the whole document when nothing is selected. Tab stops follow the tab width in Settings.

ToolWhat it does
Trim Leading / Trailing / Leading and Trailing WhitespaceRemoves spaces and tabs at the start, the end, or both ends of every line. Line endings stay.
Convert Tabs to SpacesReplaces every tab with spaces up to the next tab stop, so the text looks the same.
Convert Leading Spaces to TabsRewrites the indentation at the start of each line as tabs (plus spaces for the rest of a tab stop). Spaces later in the line stay.
Convert Line Breaks to SpacesReplaces each line break with one space. The last line keeps its line break. Unlike Join Lines, nothing is trimmed.
