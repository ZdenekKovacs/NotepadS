NotepadS Help

Getting started

Open, create and save text files.

Open and create

Choose File › Open (⌘O) to open any text file: source code, configuration files, logs, files without an extension. To see hidden files such as .env, press ⇧⌘. in the Open window. To find the files of one language, choose it from Show at the bottom of the Open window: other files are grayed out. NotepadS remembers your choice; choose All Files to see everything again. File › New (⌘N) opens a new document in a tab of the current window; the + button in the tab bar does the same.

NotepadS refuses binary files (images, archives) and files larger than 100 MB, so they can’t be damaged by mistake.

Saving and autosave

NotepadS saves your work automatically, also for documents that were never saved. When you quit and open NotepadS again, every window comes back with its text, caret and scroll position, even after a crash or a restart.

To keep a copy, choose File › Duplicate. To go back to an earlier state, choose File › Revert To › Browse All Versions.

Files changed by other apps

If another app changes an open file and you have no unsaved changes, NotepadS shows the new contents. If you do have changes, macOS asks which version to keep when you save.
