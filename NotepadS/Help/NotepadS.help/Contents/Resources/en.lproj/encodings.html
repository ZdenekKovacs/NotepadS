NotepadS Help

Encodings and line endings

NotepadS keeps every byte of a file as it was, unless you change it.

Encodings

The status bar shows the file’s encoding, for example UTF-8 or Windows-1252. NotepadS detects it when the file opens: UTF-8 and UTF-16 (with a byte order mark), otherwise Windows-1252, the most common older Western encoding.

Click the encoding in the status bar to:

  • Reopen with Encoding — read the file again in another encoding, if the text looks wrong.
  • Convert to Encoding — save the text in another encoding from now on.

If you type or paste a character the encoding can’t store (for example an emoji in a Windows-1252 file), NotepadS asks whether to convert the document to UTF-8. Nothing is inserted until you decide, so saving never loses characters.

Line endings

Text files end their lines with LF (macOS, Linux), CRLF (Windows) or CR (classic Mac OS). NotepadS keeps every line ending exactly as it is in the file, so editing one line changes only that line. New lines you type use the file’s main style.

The status bar shows the main style and (mixed) when a file uses more than one. To make them all the same, click the line ending in the status bar and choose Convert to …. One Undo restores the original line endings.
