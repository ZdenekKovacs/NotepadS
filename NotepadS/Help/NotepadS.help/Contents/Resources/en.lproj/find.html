Find and replace

Search with the find bar, or with regular expressions in the Find and Replace panel.

Find bar

Edit › Find › Find… (⌘F) shows the find bar above the text; ⌘G finds the next match and ⇧⌘G the previous one. ⌥⌘F adds a replace field.

Find and Replace panel

Edit › Find › Find and Replace with Regular Expressions… (⇧⌥⌘F) opens a panel that works on the document in front.

  • Regular expression — treat the search text as a regular expression. Without it, the text is searched for literally.
  • Ignore case, Wrap around — as their names say.
  • Replace All in selection only — limit Replace All to the selected text.

In the replacement, $1, $2 … insert the groups in parentheses, \n a line break and \t a tab. Replace All is a single Undo step. Press Return for Next and Esc to close the panel.

Example: find (\w+)@(\w+) and replace with $2: $1 turns ann@example into example: ann.

Find in Files

Edit › Find › Find in Files… (⇧⌘F) searches every file in a folder. Click Choose… to pick the folder (macOS lets NotepadS read a folder only after you choose it; choose it again after restarting NotepadS). In Files, limit the search to some files, for example *.swift *.py; a pattern starting with ! skips matching files and folders, for example !*.min.js !node_modules. Leave it empty to search all files.

Results are listed per file, with the line number and the match highlighted. Click a result to open the file at that line, or double-click a file to open it at its first match. Binary files and files over 50 MB are skipped, and each file’s encoding is detected as when you open it. The search stops after 10,000 matches; Stop ends it earlier.
